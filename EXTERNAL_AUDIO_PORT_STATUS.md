# External audio provider port status

This archive adds the MetroFuse SoundCloud and JioSaavn provider/resolution source modules under the M3-Play package namespace, plus SoundCloud auth-token normalization and provider quality enums.

**Important:** This is a backend source port only, not a completed user-facing integration. M3-Play's search screens, navigation, settings UI, media-item/queue creation, and MusicService playback resolver have not yet been wired to these providers. Do not treat SoundCloud/JioSaavn as available in the app UI until that integration is completed and tested. No credentials or API keys are embedded.
